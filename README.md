# 花火街 1.1.47（ベータ）

花火の効果音を、使用許可を得たOGAWA SOUND「FIREWORKS SFX -Japanese Hanabi-」の必要な26録音へ更新しました。3号・5号・尺・二尺の開花音、発射音、金の穂、千輪の小玉、大トラ・子トラ、かむろ・柳の尾へ割り当てています。3号5種、5号5種、尺4種、二尺2種の開花音を一巡させ、音程・音量・高域の控えめな個体差も加えています。従来の合成音は比較用に選べます。

二尺の発射・開花と千輪の小玉に低音と音圧を加えました。かむろ・柳の尾の音は、開花音から尺約1.5秒、二尺約2秒後。銀かむろの尾の録音は約1.5倍の長さにしています。大トラの連続発射は元の約0.13秒間隔を保ち、録音による発射音へ更新しました。

尺・二尺の特別玉に6種類の笛を追加しました。尺の八重芯、二尺の三重芯、四重芯・五重芯の尺と二尺が対象です。素材を一巡するまで重複させず、笛の入りは実際の発射音から約0.5秒後。Macで本人が聴き、この入りを採用しました。休止時の予約取消と途中再開を維持しています。

音楽の標準音量を35％にし、「花火を聴く／標準／音楽を聴く」と音量スライダーを用意しました。選んだMIXは曲の時計や花火の進行を変えません。3曲連続の順番は「花火の夜 → 夏の名残 → パステル・パラサイト」です。

二尺の開花中心を箱庭内の1.55から2.00へ上げました。尺の中心1.30に対し約1.54倍の高さです。二尺の上昇時間約5.6秒と点火の微差、開花半径、各曲の打ち上げ時刻は維持しています。橋・屋形船での音の距離計算は、高くなった実際の音位置に追従します。街・屋上設備・船の航行は1.1.38のままです。

既存XR・屋形船・音楽・休止再開と録音の割り当て、笛の開始0.5秒、二尺の各形状の高さと開花時刻、38ファイル・3曲のオフライン保存および更新失敗時の復旧を検証しました。Quest実機の聴感・負荷は今回の版でこれから確認します。素材は必要な録音だけをJS配列に組み込み、個別効果音WAV／OGGや素材の書き出し機能は設けていません。

QuestでWi-Fi接続後、「オフライン保存を確認・更新」から保存し、「保存済み1.1.47」と左上の1.1.47を確認してください。
