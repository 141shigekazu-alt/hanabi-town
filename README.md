# My花火街 1.2.93

Quest 3で街と音楽に合わせた花火を楽しむWebXRアプリです。大型版1.3.0の前の調整版です。

## 今回の変更

- 開演時の音響準備を軽減。停止や構成変更のたびに録音素材と残響を全部作り直していた処理を、一度準備した音のデータの再利用へ変更します。
- 停止時は従来どおりAudioContextを閉じ、鳴っている音・予約・残響を切ります。再利用するのは音のデータと調整値だけで、再生ノードや前の大会は持ち越しません。
- 保持する準備データは直近のサンプルレート１種類だけ。停止を繰り返しても履歴として増えません。
- 1.2.92の構成変更ボタン直下の完了案内と、薄くまとまった入力例を継承しています。花火の構成や音色の変更はありません。

## Questの更新

ネット接続中にリロードし「保存更新」を押します。「保存済み 1.2.93」を確認して、もう一度リロードしてからMRへ入ってください。

## 音声リクエスト（テスト版）

「演出を調整する」のマイクから最大20秒。準備中の表示が消えて録音中になってから話し、「停止」で終了できます。文字と希望を確認し、「このイメージで打ち上げる」で反映します。
「全体はしっとり、大玉はところどころ、最後は盛大に」のように全体・量・締めを分けて扱います。認識モデルは前版と同じです。通常の録音は処理後に破棄し、外部へ送りません。初回だけ端末内認識のモデルを取得します。

## 保存と配信

保存済みの構成や音源の原本は書き換えません。新しい構成は「打ち上げ玉の構成を変える」から作成してください。以前の保存済み1.2.55と別バージョンは残しています。
静的HTTPサーバーでフォルダー全体を配信できます。MRはHTTPSまたはlocalhostが必要です。ベンダーとフォントのライセンスはvendor/とfonts/に同梱しています。
