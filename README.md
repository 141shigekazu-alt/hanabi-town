# 花火街 1.1.51（ベータ・大音量と返し・笛のバランス）

本人が1.1.50をQuestで確認し、音質が大幅に良くなり、尺・二尺の返しが好評で「最初のトンネル感はまったくない」と評価しました。最後は花火100％・本体100％で鑑賞し、初期音量をなるべく大きくすること、笛を今の75％へ下げること、返しを少し長くすることを要望。さらに5号にも軽い返しを希望しました。大玉が重なった瞬間の軽い歪み・ざらつきは轟音の味として許容するという本人の判断を反映します。今回のQuestの聴感はこれから確認します。

花火の初期音量を60％から100％へ変更しました。保存済みの旧初期60％は一度だけ100％へ移行し、その他の保存値は保持します。移行後に自分で60％へ下げ直した場合は、その選択を保持します。初期状態へ戻す操作も100％です。街・音、音楽付き、MR音楽ページの連動は保持します。音楽の初期35％と保存済み20％等は保持します。

花火専用の増幅を6倍から7.2倍へ20％増やしました。音楽はこの段を通りません。コンプレッサー（閾値-6dB／ニー6dB／比率12／attack1ms／release0.15秒）、その後の0.88倍の出力余裕、最終MIXの約0.98のガードは維持します。大玉・連発は制限が働くため、聴感が全て20％増えるとは限りません。重なりの瞬間の軽いざらつきは許容しますが、新たな合成ノイズやフィードバックは足していません。

笛6種は、増幅増加分を補正したうえで、同じスライダー位置で1.1.50の75％のレベルになるよう調整しました。高音だけが全体増幅で突出しないための個別調整です。音量倍率はコンプレッサー前の値で、聴感や最終音声の振幅が一律75％になるという保証ではありません。入りは実際の発射音0.5秒後、6種の一巡と個体差、予約取消・休止再開を保持します。

尺・二尺の採用済みの反射の前半は左右ともサンプル単位で保持し、3.94／4.81秒の位置にさらに弱い二つの反射を追加しました。反射バッファは3.8→5.3秒です。最後ほど弱く高域を控えめにする音色、主録音の後半だけから送る方式、入り尺0.65秒／二尺0.75秒＋0.25秒フェード、送り20％を維持します。濃い低音リバーブへ戻さず、等間隔反復やフィードバックも使いません。

5号は旧1.25秒の薄い残響から、1.6秒の短い不規則な屋外反射へ変更しました。反射位置0.13／0.29／0.52／0.84／1.18秒、送りは主音の10％で大玉の半分、主音開始から0.55秒後＋0.25秒で薄く入れます。3号へ反射は足していません。これらのバッファ長は、開花からその秒数で全体を切る意味ではなく、録音の後半の音が終わった後にも反射が続きます。

橋の床が足にめり込んで見えるという本人の報告を調査。橋モデルの床は変更していませんでしたが、XR入場時に目線を床上1.2mへ固定する処理があり、目高1.7mでは床が実床の50cm上へ移動する条件を再現しました。橋だけはQuestのlocal-floorの床へ合わせ、立位・座位で入場時の目高に依存せず床を0mへ固定します。屋形船の採用済みの座位目線・航行・デッキ移動とMacの見え方は保持します。実際のQuestでの修正確認はこれからです。

全26点の録音素材と主録音波形、3号の音色、5号の滑らかな減衰、二尺の低音、千輪の大小差、50の不規則なカムロ尾と1.5倍の長さ・入り尺1.5秒／二尺2秒、街・屋形船、二尺中心高度2.00と上昇時間、3曲の時刻と順番「花火の夜 → 夏の名残 → パステル・パラサイト」を保持しています。素材は選んだ26点のJS配列配信で、個別効果音ファイル・書き出し機能を付けない方式です。

実アプリのXR・船・曲・休止再開・笛・高さ・音量操作と設定移行、録音の一致と笛の補正倍率・採用済み反射の左右一致、Chrome Web Audioの全開花録音・発射・笛・最大多重発音・音楽20％MIX・HRTF・複合発音・予約取消・実パステル曲末、38ファイル3曲のオフライン保存と失敗時復旧を確認しました。計算通過はQuestの聴感・実機負荷や本人が欲しい体感音圧の保証ではありません。

Questで「オフライン保存を確認・更新」から保存し、「保存済み1.1.51」→再読み込み→左上1.1.51を確認してください。今回は花火側100％が初期値です。本体は普段の60〜70％から、曲なしの3号・5号・尺・二尺と連発、笛のバランス、返しを確認し、その後音楽20％と曲末の最後の一発を聴いてください。
