# 花火街 1.1.35（ベータ）

屋形船で永代橋と清澄橋の下をくぐり、街の手前まで戻って繰り返し航行できるようにしました。出航時には永代橋が約41m前に見え、近づいていく景色を楽しめます。花火・音楽が終わったあとも船は周回します。

Uターンは一方向へ滑らかに折り返す航路へ変更し、回り始めと終わりを穏やかにしました。船らしい船首・船尾の横方向の動きは保っています。交通待ちなしの一周は約20分17秒です。

音楽パネルに「全てを続けて見る」を追加しました。「花火の夜→夏の名残→パステル・パラサイト」の順に、花火と音の余韻を待って続けて鑑賞できます。最後は船の航行が続きます。

永代橋の角度を12度に整え、両岸へ続く永代通りと歩道を追加。元の手前のビル群も配置を整え、追加した一列との間の大きな空白を街区として自然な間隔にしました。ビル80棟と窓・屋上灯・クレーンを維持しています。

Macで曲の連続・次周回・Uターンのスムーズさを本人確認済み。船体が岸と橋に収まること、25通りの交通条件で各2周以上・接触や永久停止なし、XRの座席固定と歩行、終演後周回、36ファイル・3曲のオフライン保存を検証しました。この新版のQuest 3での体感確認はこれからです。

保存済みの方はWi-Fi接続後「オフライン保存を確認・更新」→「保存済み1.1.35」→再読み込みしてください。
