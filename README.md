# 花火街 1.1.15

Quest 3の部屋に置ける花火の街。手前の橋からも鑑賞できます。

音楽付きの３曲：「花火の夜」「夏の名残」「パステル・パラサイト」。曲を選び、音楽付き大会を開始してください。

## 1.1.15の変更

- 永代橋の鮮やかな青、清洲橋を思わせる細い青の吊り橋、厩橋を思わせる明るい淡緑の三連アーチで、３橋の表情を分けました。
- 提灯と窓が灯る４隻の屋形船が、右側の航路をゆっくり行き交います。川の端で自然に現れ、消え、水面にも光が映ります。
- スカイツリーの展望台を巡るライトは、約2.5秒で一周します。
- 左岸２基・右岸１基の屋上クレーンに、塔頂とアーム先端の赤色灯を付けました。永代橋右手前の大きなビルにも赤色灯を追加しました。
- ひまわりの大きな星は、放射方向に開いた軌跡のままゆっくり減光します。うずまきにも同じ消え方を反映し、ひまわりより0.5秒長い余韻にしました。

左右の初期仕込み：右は銀かむろ尺玉、左は三重芯二尺玉。キャンディー尺玉・大星尺玉・千輪尺玉も仕込めます。子トラの1.3倍ゆったりした動き、３曲の構成・発数・締めのタイミングを維持しています。
