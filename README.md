# 花火街 1.1.36（ベータ）

一度乗った屋形船は、降りたあとも航行を続けるようにしました。街を見下ろす視点や橋の上へ移っても船は周回し、乗り直すと、その時の船へ戻れます。Uターンの途中で降りると乗っていた船と対向船が止まり続ける問題を修正しました。

クルッとパネルとMacのサイドパネルに「出航位置に戻る」を追加。一度乗船したあとに表示され、永代橋を前に見る最初の位置から再び乗れます。船内の歩行位置も戻ります。曲や花火の再生は巻き戻しません。

クルッとパネルの一番上を、標準の視点「街を見下ろす」にしました。

直進の巡航速度を従来の120％（最大0.54m/s）へ変更しました。曲がる前後は穏やかに減速・加速し、Uターンの軌跡と所要時間160秒は維持しています。交通待ちなしの一周は約18分29秒です。

Macで表示と操作を確認。実際のアプリでUターン中の下船から旋回完了・対向船の再開、途中からの再乗船、出航位置へ戻しても曲と花火が継続すること、XR座席固定・歩行・視点切替・休止復帰を検証しました。25通りの交通条件で各2周以上、船体接触と永久停止がないこと、3曲連続再生・終演後周回・36ファイルのオフライン保存を検証しました。Quest 3での新版の体感確認はこれからです。

Wi-Fi接続後「オフライン保存を確認・更新」→「保存済み1.1.36」→再読み込みし、左上が1.1.36になったことを確認してください。
