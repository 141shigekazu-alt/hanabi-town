# 花火街 ベータ版1.3.4

花火街は、Meta Quest 3（クエスト）のMRで、部屋に置いた小さな街と花火大会を楽しむWebアプリです。好きな曲を取り込んで音楽花火を自動構成。日本語の音声リクエストや、自分だけのセットリスト保存にも対応。ベータ版公開中。

公開先：https://141shigekazu-alt.github.io/hanabi-town/

## 1.3.4の改善：TCの曲名と曲選択の並び

- TCの時刻の右に、現在の曲名を表示します。構成番号は付けず、長い曲名は２行まで。曲なしの大会では曲名を表示しません。
- 標準４曲は先頭のまま、取り込み曲は変更後の表示名を日本語の名前順に並べます。アーティスト名を先頭に付けた曲がまとまります。曲の選択・名前変更・再読み込みで同じ順序になります。
- 曲を選ぶ一覧だけの変更で、保存セットリストの順番や音源・解析結果は変更しません。

## 1.3.3の変更：タイトル下から更新・保存

- タイトル近くの版表示の下に「最新版に更新・保存」を独立して表示。保存中の進捗、最新版を保存済みか、再読み込みが必要かも同じ場所で案内します。
- 新しい版を保存した後は「保存完了・再読み込み」で切り替えられます。保存曲・お気に入り・セットリスト・設定の領域は変わりません。
- 1.3.2以前を保存済みの方は、今回だけ従来の右パネル末尾から保存を更新し、再読み込みしてください。以降はタイトル下の入口を使えます。

## 1.3.2の新機能：ビルの屋上の桟敷席

- クルッとパネルの「ビルの屋上から見る」から、柵・丸テーブル・椅子のある桟敷席へ入れます。
- 最初は花火の迫力を楽しむ近い席。屋上では同じ一行で「近い席／全景の席」を選べます。サイドパネルの「街・音」からも切り替えられます。
- 近い席は木の天板と深緑の椅子、全景の席は黒い天板と落ち着いた革色の椅子。花火と食事を楽しめる少し斜めの配置です。
- 左スティックで柵のすぐ内側まで移動できます。椅子を離れると目線が約50cmなめらかに上がり、戻ると座った目線へ下がります。頭の覗き込みでは切り替わりません。
- 席や橋・船を切り替えても、大会は続きます。取り込んだ曲・お気に入り・セットリスト・設定の保存領域は同じです。

## 1.3.1の修正

- 曲名の編集で一度ブラウザへ出た後、編集欄の「MRに戻る」と通常の「MRで観る」のどちらから入っても、編集前の街の位置・向き・大きさとパネルを復元します。MR開始を拒否・失敗した場合も、復帰情報を保持して再試行できます。
- 古い位置の目印の削除が遅くても、街の配置・表示を待たせないようにしました。新しい目印の記録を、古い処理の完了で消さないようにしています。
- この２経路を模擬検証とブラウザ操作で確認しています。利用者が報告した実Questの断続的な症状の原因が、この２点だったと断定するものではありません。修正後も実機で経過を確認します。

## 1.3.0からの機能

- 自分の音楽を取り込み、端末内で解析して音楽花火を自動構成。曲調に合わせた作風・配色・花畑・海・田園などの演出を組み合わせます。
- 日本語の音声リクエストを演出へ反映するテスト版。マイクの準備表示、最大20秒の録音と手動停止、文字と希望の確認・取り消しに対応します。「このイメージで打ち上げる」を押して反映します。
- お気に入りの音楽花火と、名前付きセットリストを保存。セットリストの名前から曲目・曲順を確認し、そのままドラッグで順番変更・曲名変更・曲の除外ができます。大会は独立した▶から始めます。
- ゴールド標準とサイバーのパネル配色。街・音で切り替えられます。子パネル、連続スクロール、トリガーへの仕込み、TCと玉名、音量・部屋の明るさを調整できます。
- 花・稲穂・蝶・惑星・鼓などの演出と、開演時の音響データ再利用による負荷軽減を含みます。

## 標準の音楽花火

「花火の夜」「夏の名残」「パステル・パラサイト」「もう一度だけ」の４曲です。
標準の構成は「曲名（オリジナルプログラム）」、自動構成は「曲名　構成−１」などと表示します。自分で取り込んだ曲は、その端末に保存されます。

## Questの更新

ネット接続中にリロードし「保存更新」を押します。「保存済み 1.3.3」を確認して、もう一度リロードしてからMRへ入ってください。公開URLと既存の保存領域を維持しています。取り込んだ曲・お気に入り・セットリスト・配色設定を残すため、サイトデータを消す必要はありません。

## 音声リクエスト（テスト版）

「演出を調整する」のマイクから話します。準備中の表示が消えて録音中になってから話し、「停止」で終了できます。
「全体はしっとり、大玉はところどころ、最後は盛大に」のように伝え、文字と解釈を確認してから反映します。通常の録音は処理後に破棄し、外部へ送りません。認識モデルは初回に取得します。聞き間違いや希望の解釈には制限があり、引き続きテスト版として提供します。

## ベータ版について

1.3.0までの確認済みの機能を引き継ぎ、1.3.1でMR復帰経路を修正しています。利用者から、再現を試みると正常に動作する一時的な違和感の報告があります。原因や症状は特定できておらず、再発時に手順を確認します。
保存済み1.2.55と1.2.96の手元版は別に保持しています。今後の試作品「My花火街２」「My花火街３」などは、本家と別URL・別の保存領域で検証し、採用分を本家へ反映する方針です。

## 配信とライセンス

静的HTTPサーバーでフォルダー全体を配信できます。MRはHTTPSまたはlocalhostが必要です。ベンダーとフォントのライセンスはvendor/とfonts/に同梱しています。

## 検索からの案内

案内候補は「花火街 クエスト」「花火街 MR」。ページのタイトル・紹介文と本文、canonical、共有用メタ情報、サイトマップを整備しています。検索で見つかることや順位・反映時期はまだ確認できていません。公開URLを維持し、実際の検索結果を確認してから案内を切り替えます。検索向けの文章整備のため版は1.3.1を維持しています。
