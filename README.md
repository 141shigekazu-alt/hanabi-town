# 花火街 — 最初の夜

**ベータ版 1.1.4**。Meta Quest 3のブラウザーで、部屋にミニチュアの街を置いたり、街の橋から花火を見上げたりできるWebXR MR／VRアプリです。

[花火街を開く](https://141shigekazu-alt.github.io/hanabi-town/?build=1.1.4)

## 観る

Quest Browserで開いて「部屋で観る」へ。静かな街を好きな場所へ置いてから開演できます。「街に入る · 手前の橋」で、橋から見上げる視点へ切り替えます。

「花火大会」タブでは、曲なしの３つのプログラムを選べます。稲穂の横７玉を３回続ける幕開けと、大トラ・子トラ、大玉の見せ場があります。「音楽付き」タブでは「花火の夜」「夏の名残」を選びます。

- **花火の夜**：約２分。子トラ・ひまわり・渦巻き・二尺玉と、中盤のピラミッド。最後は金の大トラのクロス、一瞬の溜め、銀かむろ９玉へ。十分広がるのは118.25秒、曲は119.6秒。曲後も音と光の余韻が続きます。
- **夏の名残**：約３分。小玉の稲穂、大玉を一輪ずつ味わう間と、左右のトラの掛け合い。終盤の盛り上がりで銀かむろ９玉、最後は二尺玉の三重芯一発です。

稲穂は小さな星の房がゆっくり開き、垂れながら長い尾を残し、根元から消えます。横７玉ごとに方向・間隔・伸び方に違いがあり、点火・開花は約0.2秒の幅で少しずれます。昇る火は細い微光。発射音はトラと同じ系統の控えめな音、開花は短く小さな「パンッ」です。

## 操作

- 左X：クルッとメニュー。右A：サイドパネル。右B：一時停止・再開。
- 街の台座へ向けてグリップで掴んで移動。掴みながらスティックで回転・大きさを調整。
- 大会中に空へ向けてトリガーを押すと、火の点を送り、着いた場所から仕込んだ玉が一発上がります。
- 初期仕込みは **右＝銀かむろの尺玉、左＝三重芯の二尺玉**。左右の仕込みボタンで種類・大きさ・配色を選び直せます。
- パネルに向けたトリガーはボタン選択。白い棒をグリップで掴むと位置を調整できます。
- 左手のひらを上へ返すメニューと、右側の直接タッチでも操作できます。時間と玉名の小パネルも表示できます。

Macではドラッグで見回し、ホイールで距離を調整できます。

## 版と制作記録

細かな修正を反映するたびに版の最後の桁を１つ増やします。画面表示・計測結果・読込識別子を揃えています。

1.1.4では「花火の夜」の終盤へ大トラのクロスと約半秒の溜めを追加し、銀かむろ９玉を0.65秒後ろへずらしました。銀かむろの上空32,352点の密度、２曲の他の見せ場、採用済みの稲穂の造形は維持しています。

1.1.3までの音・稲穂・俯瞰と橋の鑑賞は制作者がQuestで確認し好評。1.1.4の追加クロスと最後の間は全編の描画更新・音予約と休止復帰で検証しました。今回の構成のQuestでのFPSは未測定です。
