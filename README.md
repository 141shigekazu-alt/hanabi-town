# My花火街 1.2.78 · パネル整理と風景演出の組み込み

公開URL： https://141shigekazu-alt.github.io/hanabi-town/?build=1.2.78

78公開版です。保存した曲・♥・セットリストを引き継ぎます。保存済み55と77の元ファイルも保持しています。

白いバーをグリップで動かすパネルは、床に垂直のまま左右に向きを合わせます。使い方は本文へビームを向け、スティック上下でスクロールします。スクロール中は同じスティックで街を歩きません。

主タブは「花火大会／街・音／使い方」の３つ。試し打ちは花火大会の下のボタンから開きます。右上は左から「一覧／♥」です。

TCパネルに時刻と小さな玉名をまとめました。10秒戻る／再生・一時停止／10秒送る、再生位置スライダー、セットリストの前の曲／次の曲を操作できます。終演後の再生では、名前付きセットリストの先頭へ戻ります。時間と玉名の独立パネルは表示しません。

伝統／ポップ／創造／混合の作風とは別に、花畑・穂・海・田園を選びます。使わない回も残します。花畑には黄色いタンポポと五色の花園があり、10〜15秒の下の花と上空の花を組み合わせます。長い海は９波で青と水色から夕焼へ、田園は８波で紫から緑・金へ移ります。通常の穂も、区間の長さに合わせて１〜６波を繰り返します。曲の無音、サビの合図と締め、重ねた時の描画上限を守り、置けない場面へ無理に詰め込みません。

保存した大会は同じ構成で再生します。78の新しい抽選は、曲を組み直して作った構成へ適用します。以前の♥・セットリストを自動で作り替えることはありません。

音源・解析・♥・セットリストの保存先は、その端末・ブラウザのサイト内です。77の取り込み曲などを78のキーへ引き継ぎ、元の記録を残します。MacのlocalhostとQuestの公開HTTPSは別の保存先です。

Macで操作と構成・保存の検証済みです。Quest実機の掴み心地・スクロール・MR鑑賞は本人確認待ちです。オフラインで使う場合は「オフライン保存を確認・更新」で「保存済み 1.2.78」になるまで待ち、ページを再読み込みしてください。
