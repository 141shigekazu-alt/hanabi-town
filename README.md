# 花火街 1.2.0（ベータ・実録音の花火効果音）

花火の効果音を実録音へ全面入れ替えた大型アップデートです。本人が1.1.51をQuestで確認し、本体を100％まで上げずに十分楽しめたこと、イヤホンで大きな迫力を感じたことから、今回の音を採用し、1.2.0として公開するよう指示しました。

最終調整として「金の穂」の開きのザーッという音を、1.1.51の60％へ下げました。C-B-1／C-B-2の両方に適用しています。素材を共有する大トラ・子トラの尾は、役割ごとに独立した音量なので、この調整の影響を受けません。音量倍率は花火のコンプレッサーに入る前の値です。

選んだ26点の実録音をJS配列として組み込み、3号・5号・尺・二尺の開花バリエーション、実録音の発射、大トラ・子トラ、千輪の小玉、カムロと柳の尾、6種類の笛を使用しています。通常の録音モードでは旧合成音を混ぜません。素材集全体や個別の効果音WAV／OGGを公開せず、書き出し・ダウンロード機能を付けない配信方式です。

Questで採用された1.1.51の音量と音質、花火の初期100％、音楽の初期35％と保存した20％等、尺・二尺の弱い屋外反射と5号の軽い返し、笛の控えめな音量と発射音0.5秒後の入り、不規則なカムロ尾と1.5倍の長さを引き継いでいます。録音のこもり感をもう少しクリアにしたいという所感は今後の候補として記録し、今回は金の穂の個別音量だけを調整しました。

橋の床をQuestのlocal-floorへ合わせる修正、二尺の中心高度と上昇時間、街の90棟と屋形船の速度・航行・乗降・出航位置戻し、3曲の時刻と順番「花火の夜 → 夏の名残 → パステル・パラサイト」を引き継いでいます。本人の今回の報告は音の評価であり、橋の床の実機確認結果は明示されていません。

1.1.51のChrome Web Audio62条件の通過記録に加え、変更した金の穂の2素材を44.1／48kHzで比較し、個別音量・録音と再生時刻の維持を検証しました。実アプリのXR・船・曲・休止再開・音量、38ファイル3曲のオフライン保存・更新失敗時の復旧も確認しています。1.2.0での金の穂の最終聴感は本人の次の確認で判断します。

Questでは「オフライン保存を確認・更新」→「保存済み1.2.0」→再読み込み→左上1.2.0を確認してください。既存の音量・選曲設定を引き継ぎます。
