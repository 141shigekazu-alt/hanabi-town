# My花火街 1.2.90

Quest 3で街と音楽に合わせた花火を楽しむWebXRアプリです。大型版1.3.0の前の調整版です。

## 今回の変更

- お気に入りは曲名を大きく表示し、構成番号・曲調・再生時間を下段へ集約。以前の自動保存名も表示時だけ整理し、自分で付けた名前は保ちます。
- MRのお気に入りとセットリストは連続スクロール。ビームを一覧へ向けてスティック上下、または右のスクロールバーをトリガーで操作。並べ替えは引き続き左端のつまみを使います。
- 金色主体の自動構成は約４割の上空の玉に色の親星を使い、約６〜７割に増やした彩り豊かな回も抽選。色は小さな芯や先端だけでなく外側全体に見せ、金色の穂・地上と残りの玉をベースにします。
- 冒頭は菊・芯入りなどから入り、蝶・惑星・鼓はその後へ。曲の解析区切りと最初の数発を考慮します。
- 蝶は自然な向きを広く分散。５号・尺に加えて３号を追加し、花の絨毯に３号または５号の３羽を重ねる抽選を追加。花畑の小花・緑の茎と葉を保ち、３羽はまとめて確保します。
- 解析のinstrumental区間も花畑の候補に含めます。地上を含む同時描画量を確認してから新しい構成を確定します。

## Questの更新

ネット接続中にリロードし「保存更新」を押します。「保存済み 1.2.90」を確認して、もう一度リロードしてからMRへ入ってください。

## 音声リクエスト（テスト版）

「演出を調整する」のマイクから最大20秒。準備中の表示が消えて録音中になってから話し、「停止」で終了できます。文字と希望を確認し、「打ち上げ玉の構成を変える」で反映します。
「全体はしっとり、大玉はところどころ、最後は盛大に」のように全体・量・締めを分けて扱います。認識モデルは前版と同じです。通常の録音は処理後に破棄し、外部へ送りません。初回だけ端末内認識のモデルを取得します。

## 保存と配信

保存済みの構成や音源の原本は書き換えません。新しい構成は「打ち上げ玉の構成を変える」から作成してください。以前の保存済み1.2.55と別バージョンは残しています。
静的HTTPサーバーでフォルダー全体を配信できます。MRはHTTPSまたはlocalhostが必要です。ベンダーとフォントのライセンスはvendor/とfonts/に同梱しています。
