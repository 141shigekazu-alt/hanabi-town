# 花火街

部屋の中にミニチュアの街を置いたり、街の橋の上に座る視点で花火大会を眺めたりできるWebXR MR／VRアプリです。Meta Quest 3のQuest Browserで利用します。

## バージョン

現在の版は `beta.1.0.19` です。画面表示・MR計測JSON・読み込み識別子に同じ番号を使います。

- `beta.1.0.19` → `beta.1.0.20`：通常の調整・修正。
- `beta.1.1.0`：まとまった機能追加。末尾は0に戻します。
- `beta.2.0.0`：大型修正・大幅な刷新。後ろの2つは0に戻します。

全種類に一玉ごとの形の個性を追加しました。同じ種類・号数の3発ごとに、丸い玉・うっすら歪む玉・少し崩れる玉が1発ずつ入るよう、順番をランダムにします。二尺のかむろにも丸い玉が混じり、その玉は星の伸び方を揃えて球状に開きます。3号の単色菊は一部が縦長・横長に、5号は控えめ、尺玉は最も安定、二尺はかむろを基準に揺らぎを付けます。この強さは制作者の実物観察に基づく作品内の調整値です。

芯と外星は歪みの軸を共有し、芯は控えめにします。ひまわり・渦巻きは模様を読み取れる範囲に抑え、千輪は子花火の広がる位置にも適用します。形は打ち上げ時だけで決め、開花中や尾を描くときに引き直しません。形用の乱数は街・大会・かむろの既存乱数と独立しています。火花数・色・寿命・上昇・音・大会の間・解像度は維持しています。

ひまわりと渦巻きの開花面は一玉ごとにランダムな3次元方向へ回転し、開花中は固定します。公開後の全体の鑑賞体験は制作者から好評です。形の個性の追加後も制作者から「明らかにリアル」と評価を得ました。今回の開花・音・川面の調整と四重芯・五重芯はQuest実機での鑑賞・性能評価前です。

旧版 `1.0.0-beta.2` の特別かむろはQuest実機で32,352点を維持し、重い区間の平均30.1fpsから81.7fpsへ改善を確認済みです。過去の計測ファイルは旧版番号のまま残します。

## 四重芯・五重芯

四重芯は外星＋4芯の5層、五重芯は外星＋5芯の6層です。どちらも尺玉・二尺玉から選べ、「一玉を選んで見る」またはMR操作パネルの種類欄から試し打ちできます。外から青・紅・緑・黄・紫、五重芯は最内層に水色を加えます。制作者のnoteの断面図とCGイメージを参考にした演出で、写真や実測軌道を再現したものではありません。

内側から外へ約0.1秒の着火差を付け、星は開花直後から移動し、火が入った層から光ります。全層で形の歪みの軸を共有し、芯の歪みは控えめにします。川面も5層・6層の色を使い、まだ光っていない層は映しません。波紋の球状近似のため、全火花の個別鏡映ではありません。

一発の点数は尺玉の四重芯8,250点・五重芯8,910点、二尺玉の四重芯11,550点・五重芯12,470点。高解像度化は行っていません。大会中の一玉を味わう特別玉は、二尺の三重芯→尺の四重芯→尺の五重芯を大会ごとに交代します。最初の大会は従来の三重芯で、特別玉の前後の間と千輪・かむろの見せ場は保っています。三重芯の専用試し打ちボタンも従来どおりです。

## 同時打ちの開花と川面

同じ発射時刻の玉は発射を揃え、導火線のばらつきを参考に開花を少しずらします。同時打ちの開花は全体で約0.16〜0.24秒の範囲に散らし、並ぶ順に固定せず毎回入れ替えます。単発も約0.01〜0.10秒の違いを付けます。実物の導火線寸法を再現する数値ではなく、作品の演出調整です。

開花音は同じ開花時刻を使い、従来の号数ごとの音の到着差を保って音声時計へ予約します。音そのものや余韻は変更していません。試し打ちの切り替え・停止・一時停止では未再生の予約音を取り消し、すでに響いている余韻は残します。

川面の色は実際に光っている星の位置・広がり・明るさから更新します。開花直後の一点から完成した色の輪を先に映さず、星が広がるのに合わせて映りも育ちます。千輪は割り火薬の短い閃光や、子花火がまだ暗い間に星の色を先に映しません。落下や消え方にも追従します。水面の波紋と球状の近似描画は維持しており、花びらや全ての火花の形を個別に鏡映する方式ではありません。

## 配色・連続打ち

- 芯入りは12配色。配色名は「外星 × 芯星」の順です。3号・5号・尺玉で選べます。元の桃紅×淡金も残しています。
- 単色の菊は3号限定、金・紅・青・緑・桃・紫・白・水色の8色。芯を付けず、各玉の火花と尾を同じ色にします。
- 「一玉を選んで見る」の配色欄で選んで試し打ちできます。MRパネルの試し打ちにも配色選択があります。配色は再読み込み後も保存します。
- 「おまかせ」では、七色の流し打ち／両岸の掛け合い／菊の横一列と大玉／上下二段の彩り／金の菊と柳から異なる3演出を組み合わせます。低い菊7発の一斉打ち、菊5発＋上段の芯入り5号3発などを含みます。
- 「おまかせ」を選んで「スターマインを上げる」を押すと、新しい連続打ちを単独で試せます。大会を始めると5分の構成で鑑賞できます。雰囲気の選択は従来の2段階です。
- 一玉を味わう章、特別玉の前の静かな間、従来のかむろフィナーレは保持。通常の新演出は最大8玉、かむろの特別締めは従来の9玉・32,352点です。
- 添付写真は配色と高低・左右の構図の参考に使い、画像そのものはアプリに収録していません。写真の火花数や煙・噴水を再現したものではありません。

## Quest 3で使う

1. Quest Browserで公開HTTPS URLを開きます。
2. 左上の版表示が「beta.1.0.19」になっていることを確認します。
3. 「自分の部屋で見る」を押し、ブラウザのMR許可画面に従います。
4. 街を置くと、自動で花火大会が始まります。

部屋の明るさや街の大きさ・高さは、MRの操作パネルで調整できます。MR終了は操作パネルの「鑑賞を終了してページへ」でブラウザ画面に戻れます。

## 橋の上から見る

「街に入る · 手前の橋」で、一番手前の橋に座る視点へ切り替えます。QuestのページからはVRで入れます。MR鑑賞中も操作パネル下の同じボタンで切り替えられ、部屋を隠して夜の街を表示します。

顔を上げて花火を、下を向いて川面を、左右を向いて街を眺められます。歩く・スティックで移動する操作はありません。花火大会は切り替え前の続きから流れ、同じボタンの「ミニチュアに戻る」で街全体の鑑賞へ戻れます。部屋の表示はMRから入った場合に戻ります。VRを終了する場合は、操作パネルの「鑑賞を終了してページへ」を押してください。

左コントローラーを握った手、またはコントローラーなしの左手を、手のひらが上に向くように返すと、小さな視点選択パネルが出ます。手を目線の少し下まで上げ、返したまま約0.3秒保ちます。上向きで持ち続けても繰り返し開きません。パネルは手を下ろしても残り、右手の人差し指でパネルに直接触れて選べます。指を離してから再び触れると次のクリックになります。コントローラーを持っている場合は、右コントローラー先端の小さな金色の目印で同じように直接タッチできます。タッチのときにトリガーを押す必要はありません。ビーム＋トリガーも使えます。手だけの操作はQuestのハンドトラッキングを有効にしてください。

通常の操作パネルは左Xで開閉、ビーム＋トリガーで操作できます。橋の視点では街の縮尺・床の高さ・距離・部屋の明るさは固定し、ミニチュアへ戻ると元の設定・配置を復元します。PCでは画面上の橋の視点へ切り替わり、ドラッグで上下左右を見回せます。

初版の街は既存モデルを100倍にした演出上の大きさです。橋の床から視点まで約1.2m、街の幅約320m。建物の作り込みは今後の課題です。音の素材・余韻は維持し、橋の視点では視点と打ち上げ位置の距離による到達差と、顔の向きに追従する立体音響を使います。

## 小さなガラスパネル

左手のひらを上に返して出す「鑑賞メニュー」の「時間と玉名を表示」で、経過時間と打ち上がった玉の名前だけを表示できます。同じメニューの「時間と玉名を隠す」で消せます。右の人差し指、または右コントローラー先端でタッチします。初期状態は非表示。ページにも同じ表示切り替えボタンがあります。

MR・VRでは視界の少し右下、約60cm先に、手で届く範囲に背景の透ける小さなパネルを置きます。顔を上げても頭に張り付いて追いかけず、表示した場所に留まります。橋／ミニチュアの切り替え時や一度隠して再表示したときは、新しい目線を基準に置き直します。操作パネルを閉じても残ります。下の細い白いバーにビームを合わせてトリガーを押したまま動かすと、好きな位置に置けます。手だけの場合は、バーの近くで右の親指と人差し指をつまんで動かし、開くと離せます。追跡が切れたときやパネルを隠したときは掴みを解除します。

経過時間は大会の時計を使い、一時停止中は止まります。「試し打ち」「ひと休み」「大会終了／開始前」も時間の横で区別します。玉名は打ち上がった瞬間から表示し、上昇中に次の玉の種類・号数が分かるようにします。開花後も消えるまで表示を保ちます。同じ種類・号数の同時打ちは「×5」などとまとめ、異なる玉は併記。消えた玉の名前を残さず、打ち上げ中・開花中の玉がなくなったら「次の一玉を待つ」と表示します。千輪の子花火を待つ暗い間も、その玉の名前を保ちます。配色や章名・設定は載せません。beta.1.0.17の基本操作は制作者がQuest実機で成功を確認しました。今回の発射時の玉名表示は実機確認前で、性能の追加測定は未実施です。

## MR操作

- 左コントローラーのX：操作パネルの表示・非表示。
- コントローラーのビーム＋トリガー：パネルを操作。
- パネル下の白い横棒：ビームを合わせ、トリガーを押したままパネルを動かす。
- 左トリガー：パネルや白い横棒以外にビームを向けて街の位置を合わせる。街を掴む操作ではありません。
- パネルを閉じた状態の右トリガー：大会を一時停止・再開（試し打ちモードでは大会を自動開始しません）。
- 「大会を止める」や試し打ちのボタン：試し打ちモード。大会へ戻るには「花火大会を始める」または「大会を最初から」を押します。

## 音と保存設定

「街と音」のパネルで音・音量・塔のライトアップを選べます。制作者が好評とした音は「リアル寄せ合成（テスト）」です。初回は既存実装の「現在の音」が選択されます。音の選択などはブラウザのサイト別設定に保存するため、別のURLで初めて開く際には選び直してください。

## 配信・更新

静的なHTML・JavaScript・音声ファイルだけで動作し、ビルド処理は不要です。MRにはHTTPS、またはQuest側のlocalhost接続が必要です。通常のLAN内HTTPではMRを開始できません。

更新時は `index.html`、`app.js`、`programs.js` の `?v=` をすべて同じ新しい値に揃えます。現在の値は `beta.1.0.19` です。番号を更新する際は、`app.js` の `BUILD_VERSION` も同じ値に揃えます。

## 計測

「MR実機テスト」から計測結果を保存できます。表示されるFPSはXRコールバックの間隔から求めた値で、GPU・コンポジターの実測FPSではありません。初回のQuest実測では特別かむろ32,352点、最低28.7fpsを記録しました。約3万点の密度と迫力を優先し、FPSだけを理由に点数を減らしません。旧版 `1.0.0-beta.2` では点数を維持し、計測JSONに花火・灯り・パネル更新のCPU時間（`meanUpdateCpuMs`）も追加しました。この値はGPU時間やブラウザ全体のCPU時間ではありません。
