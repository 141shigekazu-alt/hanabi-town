# 花火街 1.1.38（ベータ）

永代通りの道路と歩道を撤去し、元の70棟を元の街区配置へ戻しました。手前の空き地に低層ビルを左右5棟ずつ追加しています。永代橋の角度12度は維持しています。

屋上の赤色灯とクレーンが古い座標を参照していた不具合を修正しました。建物と屋上設備が共通の屋上情報を参照するようにし、全赤色灯の支柱と3基のクレーンの基部が実際の屋根に載っていることを確認しています。

屋形船は直線の全区間にわたり加減速していました。直進の巡航上限を0.54から0.70m/sへ上げ、加速と減速を直線の始め・終わりの各20秒に絞りました。折り返し用の交通予約中も、安全に進める接近区間は進み、旋回開始点で必要な場合に待つようにしました。船体の接触判定を維持しています。Uターンの軌跡と旋回120秒は維持し、待ちなしの一周は約11分24秒です。

帰路で永代橋の位置を通ってから手前の旋回開始点まで、交通なしの計算で約124.5秒から70.8秒へ短縮。初期交通を含むシミュレーションでは約131.5秒から70.8秒です。Quest実機の速度・体感・FPSの確認はこれからです。

交通25条件、乗船時刻・途中の一時停止・出航位置戻し・10/30/72Hzを変えた36条件で、すべて2周以上航行し、船体接触と停止し続ける状態がないことを確認しました。鑑賞船の最大連続停止は約5.1秒です。90棟の重なり、窓の配置、屋上設備の支持、既存の色と乱数の保持、XRの追跡・歩行・視点切替、3曲連続、終演後の周回、36ファイル3曲のオフライン保存と更新失敗時の復旧を検証しました。

下船後の航行、現在位置からの再乗船、「出航位置に戻る」、曲と花火の継続、先頭の「街を見下ろす」は維持しています。

QuestでWi-Fi接続後「オフライン保存を確認・更新」→「保存済み1.1.38」→再読み込みし、左上が1.1.38になったことを確認してください。
