# 花火街 1.1.29（ベータ）

屋形船の船首を長く、細身に見える形へ改善しました。屋根前端から上の先端までの張り出しを1.1.27の２倍に伸ばし、水面側は屋形の前端の下まで切り欠いています。背景４隻と乗船用の船が対象です。

船体の頂点数・描画部品数は維持。屋根・客室・提灯・デッキ・航路・鑑賞視点・３曲と音は継承しました。船首の延長に合わせ、船間隔と接触判定を調整しています。

屋形船は永代橋側から清澄橋の下をくぐり、奥の三連橋の手前で折り返します。渋滞がない一周は約11分3秒、最大約0.51m/s。デッキ内は実空間の歩行と左スティック移動に対応し、MacではWASDを使えます。

Macで船首の新旧比較・本体描画を確認。船首方向、岸と橋くぐり、約33分の交通、船体間約10mの追従間隔、デッキ歩行、オフライン保存35ファイル・３曲を検証しました。1.1.29のQuest実機確認・実FPS測定は未実施です。
