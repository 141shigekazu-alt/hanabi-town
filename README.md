# My花火街 1.2.91

Quest 3で街と音楽に合わせた花火を楽しむWebXRアプリです。大型版1.3.0の前の調整版です。

## 今回の変更

- 名前をブラウザで変更してMRへ戻った時、街の位置・向き・大きさを引き継ぎます。対応端末では一時的な空間アンカーを使い、セッションの原点が変わっても復帰します。使用後にアンカーを削除し、頭を向け直しただけでは街を移動させません。通常・ジオラマ・保存一覧の位置を保持します。
- 「解析をやり直す」のすぐ下に「打ち上げ玉の構成を変える」。音声の希望が未反映の時だけ「このイメージで打ち上げる」に変えて強調します。構成ができたら「大会に戻る」から戻り、開演を選びます。
- 文字起こしの右下に押しやすい「取り消す」。未反映・反映後・希望を読み取れなかった入力も消せます。次の組み直しには古い声の希望を持ち越さず、再録音できます。すでに準備した花火や保存原本を、取り消しだけで勝手に上書きしません。
- 「ぽつりぽつり」は元の玉を単純に間引く方式をやめ、音楽が鳴っている間に一輪ずつ、およそ４〜５秒おきに開く構成を作ります。大きさ指定がない時は５号を軸に尺を交ぜ、３号単発ばかりにはしません。明示した小玉/大玉と、最後だけ盛大/静かな余韻の指定は引き続き尊重します。
- 1.2.90の保存一覧スクロール・金色回の彩り・普通の幕開け・花畑と蝶３羽を継承しています。

## Questの更新

ネット接続中にリロードし「保存更新」を押します。「保存済み 1.2.91」を確認して、もう一度リロードしてからMRへ入ってください。

## 音声リクエスト（テスト版）

「演出を調整する」のマイクから最大20秒。準備中の表示が消えて録音中になってから話し、「停止」で終了できます。文字と希望を確認し、「打ち上げ玉の構成を変える」で反映します。
「全体はしっとり、大玉はところどころ、最後は盛大に」のように全体・量・締めを分けて扱います。認識モデルは前版と同じです。通常の録音は処理後に破棄し、外部へ送りません。初回だけ端末内認識のモデルを取得します。

## 保存と配信

保存済みの構成や音源の原本は書き換えません。新しい構成は「打ち上げ玉の構成を変える」から作成してください。以前の保存済み1.2.55と別バージョンは残しています。
静的HTTPサーバーでフォルダー全体を配信できます。MRはHTTPSまたはlocalhostが必要です。ベンダーとフォントのライセンスはvendor/とfonts/に同梱しています。
