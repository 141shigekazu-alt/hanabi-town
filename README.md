# 花火街 1.1.13

Quest 3の部屋に置ける花火の街。手前の橋からも鑑賞できます。

音楽付きの３曲：「花火の夜」「夏の名残」「パステル・パラサイト」。曲を選び、音楽付き大会を開始してください。

パステル・パラサイトはキャンディー大トラ／子トラ、単色・多色玉、大星、左右のキャンディー千輪を使ったスターマインです。５連はイントロ明け18.2秒から。2:07〜2:18は足元で溜め、2:18から終幕へ駆け抜け、銀かむろ５号５発と大星尺玉３発で締めます。

左右の初期仕込み：右は銀かむろ尺玉、左は三重芯二尺玉。

本人提供の３曲は有料SUNOで制作され、本人から商用利用・リポジトリ収録・公開の許可を受けています。参考録音の素材は含めていません。Three.jsのライセンスはvendor/LICENSEをご覧ください。

1.1.13では、配色・星数・曲の構成を保ってキャンディーの点径と発光を調整。上昇の火は普通の玉と同じ太さ、大星だけ開花後に少し大きくし、色付き子トラの過大な点径を抑えています。

締めの銀かむろ５号５玉とキャンディー大星尺玉３玉を、発射から開花まで２秒後ろへ移しました。曲後の光と花火の音の余韻を最後まで残します。

1.1.13では、本人のQuest鑑賞を受け、最後の８玉を1.1.12からさらに１秒遅らせています。
