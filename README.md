# 花火街1.2.20・静寂から最後の水色二尺

本人の指定に合わせ、最初のサビは0:56.7、その繰り返しは1:10.6、２コーラス目のサビは2:05.8、大サビの同時開花は3:15.05へ移動。トラの同時吹上も一緒に移動。

1:40以降と2:33以降に、水色・青を中心とした３号、５号などを散発的に追加。大サビからは前の玉が消える前に次の玉を重ね、3:15.05〜3:47.5に上空の開花が途切れない流れを作る。雨の穂も併用。長い尾や星数を減らして密度を作らない。

鑑賞後の本人指定に合わせ、最後のカムロ尺玉６発・５号６発だけ撤去。雨の穂も3:50.27頃に消え、静寂のあと3:57に水色二尺が一輪開く。二尺の形・色・消え方は前版と同一。音源は4:00で終了し、二尺の残光は4:01.6頃まで。終演は余韻が消えてから。

金の穂・水色／青の雨の穂に共通する「ザーッ」の効果音を、従来の60％へ変更。音源や効果音の長さは保持。

曲の時計・５秒／10秒戻る・５秒進む・停止再開・0.1秒刻みスライダーを保持。再生中の移動は再生を続け、停止中の移動はその場面で止める。巻き戻し時も玉・穂・トラを同じ形へ再構成し、過去の音を鳴らし直さない。確認する場面の一覧は小数秒も表示。

雨の曲だけ、上空の予約枠を14玉へ拡張。計算上の最大上空粒子点は98,692点。星数・尾・寿命は採用済み素材のまま。Macで進行と描画を確認し、Quest実機での性能・鑑賞評価は未確認。

TCの総尺を小さくし、現在時刻を大きく表示。Macでは「掴んで移動」のつまみをドラッグして好きな場所へ置ける。キーボードの矢印でも移動できる。画面外へ出ないように制限し、画面サイズ変更時にも位置を調整する。曲の再生位置・カメラ・花火は移動で変わらない。
