# 花火街 1.1.18

街・花火・音楽付き３曲を、Quest Browserの中に保存できるようにしました。

通信できる場所で最初の画面の「オフライン用に保存」を押し、「保存済み 1.1.18」になるまで待ってください。約89MBの空き容量が必要です。ページをお気に入りに入れておけば、Wi-Fiが使えない場所でもお気に入りから開けます。Google検索はオフラインでは使えません。

外出前にQuestのWi-Fiを切り、ブラウザを開き直して街・曲の再生・MR入室を確認してください。ブラウザの保存データ削除や端末による保存領域の整理後は再保存が必要です。将来の更新時は通信できる場所で「オフライン保存を確認・更新」を押し、保存後にページを再読み込みしてください。

途中で保存に失敗した場合は未完成の版を使用せず、前の保存済み版を保持します。全データの一致を確認してから保存完了にします。

既存の花火大会・曲付き３曲・街並み・ジオラマ・左右のトリガー仕込みを保持しています。Macで配信サーバー停止後の再読み込みと３曲の再生を確認しました。Quest実機のオフライン再起動・MR鑑賞は確認待ちです。
