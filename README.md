# 花火街 1.1.17

机の上に置けるジオラマ鑑賞を追加しました。

Questではクルッとパネルで「橋の上」「ジオラマサイズ」「通常サイズ」を選べます。ジオラマは幅約58cm・奥行約38cm、テーブル高さ75cmから始まり、グリップで上下を含め好きな位置へ動かせます。掴みながらスティックで回転・大きさを調整できます。通常サイズに戻すと元の街の配置へ戻ります。

既存の花火大会・曲付き3曲・街並み・左右のトリガー仕込みは保持しています。
