# 花火街 1.1.49（ベータ・末尾の余韻と花火音量）

1.1.48をQuest 3で確認した本人から「だいぶ良くなった」「パステル・パラサイトの最後も違和感なかった」と評価を受けました。今回は、もう少し欲しい音の末尾の余韻と、小さかった花火の初期音量を調整します。今回の聴感の採否は、Quest実機でこれから確認します。

花火の初期音量を30％から60％へ変更しました。既存の30％設定も一度だけ60％へ移行し、それ以外の保存済み音量は保持します。移行後に自分で30％を選び直した場合は、その選択を保持します。上限は100％です。「街・音」の名称を「花火の音量」とし、音楽付きの画面とMRの音楽ページにも同じ調整を追加しました。両方の画面の操作は連動し、花火の音量変更で曲の時刻や再生を戻しません。音楽の初期値35％と保存済み20％等は保持します。

5号・尺・二尺の開花録音の後半だけに、軽い短い余韻を追加しました。録音の主音の立ち上がりはそのまま、録音開始点を考慮して開花から5号0.55秒・尺0.65秒・二尺0.75秒後まで追加分をゼロにし、その後0.25秒で薄く入れます。送り量は主音の16％で、180～2400Hzの広い帯域・長さ1.25秒の減衰する残響です。一定間隔の反復エコーや長い低域の人工残響には戻していません。録音の後半を送るため、追加残響の開始から1.25秒で全体を切る処理ではありません。3号・発射音にはこの追加余韻をかけません。

3号の自然な発射・開花と各玉の録音バリエーション、1.1.48の5号の滑らかな減衰、二尺の低音補強・音圧、千輪の大小差、かむろ尾の長さと尺1.5秒・二尺2秒後の入り、笛の入り0.5秒と録音6種を保持しています。今回の音量はマスターの設定変更であり、録音自体の固定倍率を追加していません。制限器が働く大きな音・多重発音もあるので、聴感が全て一律2倍になるとは限りません。

街・屋形船、二尺の中心高度2.00と元の上昇時間、3曲の順番「花火の夜 → 夏の名残 → パステル・パラサイト」と演目時刻は保持します。必要な録音26点をJS配列で組み込む方式、効果音の個別ファイル・書き出し機能を設けない方式も保持します。

実アプリのXR・船・曲・休止再開と笛・高さ、設定移行と音量操作、Chrome Web Audioでの立ち上がり一致・末尾の追加分・多重発音・100％設定・音楽20％とのMIX・予約取消・実曲終了後の最後の二尺、38ファイル3曲のオフライン保存と失敗時復旧を確認しました。数値確認はQuestの聴感や実機負荷の保証ではありません。

Questで「オフライン保存を確認・更新」から保存し、「保存済み1.1.49」→再読み込み→左上1.1.49を確認してください。花火音量60％のまま曲なしで主音と最後の余韻を確認し、その後、音楽20％で聴き比べてください。花火の音は音楽付きの画面からも100％まで上げられます。
