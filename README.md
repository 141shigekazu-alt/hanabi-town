# 花火街 1.1.20

クルッとパネルに「屋形船から見上げる」を追加。停泊した屋形船の上のデッキから提灯と川面越しに花火を観られます。船の航行はありません。

橋ではパネルを閉じて左スティックで前後左右へ最大0.65m/sで移動。柱間約2.9m×1.5mが範囲。身体の動きは従来どおり追跡。Macでは橋視点でWASD移動、ドラッグで見回せます。

1.1.19の終演直前の追加玉静止修正を継承。本人Quest確認で最低18FPSまで下がっても最後まで終演しました。追加機能のQuest確認はこれからです。
