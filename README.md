# 花火街 1.2.27

[Quest・Macで観る](https://141shigekazu-alt.github.io/hanabi-town/?build=1.2.27)

川と橋のある小さな街で、花火と音楽を眺めるWebXRのベータ版です。Questでは部屋・橋・ジオラマ・屋形船から鑑賞できます。

「全てを続けて見る」の順番は、花火の夜 → 夏の名残 → パステル・パラサイト → もう一度だけ。曲選択と連続再生は同じ一覧の順番を使います。

Questの大サビでの音切れを抑えるため、星の重複計算を整理し、細かな音の3D定位を軽くしています。橋・屋形船で本人が音切れの解消を確認しています。
TCはクルッとパネルから大会開始前にも表示でき、曲のスライダー・巻き戻し・停止再開をまとめています。サイドパネルの右Aでの復帰も修正しました。
「もう一度だけ」は、1:37と2:34から温かい思い出の色を加え、最後の3:57の水色二尺一輪だけに笛と大きめのリバーブを付けています。配色・最後の響きと笛はQuestで本人が採用しています。

初回はネットにつないで開いてください。４曲と街・花火は「オフライン保存を確認・更新」で保存できます。以前の版を保存していた場合は保存済み1.2.27を確認し、再読み込み後に左上が1.2.27になっているか確認してください。

四曲の実音源の割当・連続再生の切替・47ファイルのオフライン保存と失敗復旧を検証。全曲通しの実機負荷・聴感は鑑賞環境でも変わります。
