# 花火街

部屋の中にミニチュアの街を置いたり、街の橋の上に座る視点で花火大会を眺めたりできるWebXR MR／VRアプリです。Meta Quest 3のQuest Browserで利用します。

## バージョン

現在の版は `1.1.0` です。画面表示・MR計測JSON・読み込み識別子に同じ番号を使います。

- `beta.1.0.29` → `1.1.0`：操作系・入室体験を含む大型更新の区切り（制作者指定）。
- `beta.1.1.0`：まとまった機能追加。末尾は0に戻します。
- `beta.2.0.0`：大型修正・大幅な刷新。後ろの2つは0に戻します。

全種類に一玉ごとの形の個性を追加しました。同じ種類・号数の3発ごとに、丸い玉・うっすら歪む玉・少し崩れる玉が1発ずつ入るよう、順番をランダムにします。二尺のかむろにも丸い玉が混じり、その玉は星の伸び方を揃えて球状に開きます。3号の単色菊は一部が縦長・横長に、5号は控えめ、尺玉は最も安定、二尺はかむろを基準に揺らぎを付けます。この強さは制作者の実物観察に基づく作品内の調整値です。

芯と外星は歪みの軸を共有し、芯は控えめにします。ひまわり・渦巻きは模様を読み取れる範囲に抑え、千輪は子花火の広がる位置にも適用します。形は打ち上げ時だけで決め、開花中や尾を描くときに引き直しません。形用の乱数は街・大会・かむろの既存乱数と独立しています。火花数・色・寿命・上昇・音・大会の間・解像度は維持しています。

ひまわりと渦巻きの開花面は一玉ごとにランダムな3次元方向へ回転し、開花中は固定します。公開後の全体の鑑賞体験は制作者から好評です。形の個性の追加後も制作者から「明らかにリアル」と評価を得ました。今回の開花・音・川面の調整と四重芯・五重芯はQuest実機での鑑賞・性能評価前です。

旧版 `1.0.0-beta.2` の特別かむろはQuest実機で32,352点を維持し、重い区間の平均30.1fpsから81.7fpsへ改善を確認済みです。過去の計測ファイルは旧版番号のまま残します。

## 街を回して眺める

ビルの正面・裏面・左右の４面に窓の灯りを配置しています。各面で点灯する部屋を変え、全窓を一律には光らせません。窓は１つの点群で描き、窓用の追加描画パスは増やしていません。建物の配置・高さ、これまでの正面の窓や灯り、花火のばらつきは維持しています。24の裏面・側面と窓の色はQuestでの確認前です。暖かな電球色を中心に、琥珀色・柔らかな白・薄い青白色を混ぜています。ビルごとに主な色を変え、一部の部屋には違う色と明るさを付けます。色のばらつきは固定し、鑑賞中に点滅させません。

## 四重芯・五重芯

四重芯は外星＋4芯の5層、五重芯は外星＋5芯の6層です。どちらも尺玉・二尺玉から選べ、「試し打ち」タブまたはMR操作パネルの種類欄から試し打ちできます。外から青・紅・緑・黄・紫、五重芯は最内層に水色を加えます。制作者のnoteの断面図とCGイメージを参考にした演出で、写真や実測軌道を再現したものではありません。

内側から外へ約0.1秒の着火差を付け、星は開花直後から移動し、火が入った層から光ります。全層で形の歪みの軸を共有し、芯の歪みは控えめにします。川面も5層・6層の色を使い、まだ光っていない層は映しません。波紋の球状近似のため、全火花の個別鏡映ではありません。

一発の点数は尺玉の四重芯8,250点・五重芯8,910点、二尺玉の四重芯11,550点・五重芯12,470点。高解像度化は行っていません。大会中の一玉を味わう特別玉は、二尺の三重芯→尺の四重芯→尺の五重芯を大会ごとに交代します。最初の大会は従来の三重芯で、特別玉の前後の間と千輪・かむろの見せ場は保っています。三重芯の専用試し打ちボタンも従来どおりです。

## 同時打ちの開花と川面

同じ発射時刻の玉は発射を揃え、導火線のばらつきを参考に開花を少しずらします。同時打ちの開花は全体で約0.16〜0.24秒の範囲に散らし、並ぶ順に固定せず毎回入れ替えます。単発も約0.01〜0.10秒の違いを付けます。実物の導火線寸法を再現する数値ではなく、作品の演出調整です。

開花音は同じ開花時刻を使い、従来の号数ごとの音の到着差を保って音声時計へ予約します。音そのものや余韻は変更していません。試し打ちの切り替え・停止・一時停止では未再生の予約音を取り消し、すでに響いている余韻は残します。

川面の色は実際に光っている星の位置・広がり・明るさから更新します。開花直後の一点から完成した色の輪を先に映さず、星が広がるのに合わせて映りも育ちます。千輪は割り火薬の短い閃光や、子花火がまだ暗い間に星の色を先に映しません。落下や消え方にも追従します。水面の波紋と球状の近似描画は維持しており、花びらや全ての火花の形を個別に鏡映する方式ではありません。

## 配色・連続打ち

- 芯入りは12配色。配色名は「外星 × 芯星」の順です。3号・5号・尺玉で選べます。元の桃紅×淡金も残しています。
- 単色の菊は3号限定、金・紅・青・緑・桃・紫・白・水色の8色。芯を付けず、各玉の火花と尾を同じ色にします。
- 「試し打ち」タブの配色欄で選んで試し打ちできます。MRパネルの試し打ちにも配色選択があります。配色は再読み込み後も保存します。
- 「おまかせ」では、七色の流し打ち／両岸の掛け合い／菊の横一列と大玉／上下二段の彩り／金の菊と柳から異なる3演出を組み合わせます。低い菊7発の一斉打ち、菊5発＋上段の芯入り5号3発などを含みます。
- 「おまかせ」を選んで「スターマインを上げる」を押すと、新しい連続打ちを単独で試せます。大会を始めると5分の構成で鑑賞できます。雰囲気の選択は従来の2段階です。
- 一玉を味わう章、特別玉の前の静かな間、従来のかむろフィナーレは保持。通常の新演出は最大8玉、かむろの特別締めは従来の9玉・32,352点です。
- 添付写真は配色と高低・左右の構図の参考に使い、画像そのものはアプリに収録していません。写真の火花数や煙・噴水を再現したものではありません。

## Quest 3で使う

1. Quest Browserで公開HTTPS URLを開きます。
2. 左上の版表示が「1.1.0」になっていることを確認します。
3. 最上段の「部屋で観る」を押し、ブラウザのMR許可画面に従います。
4. 街を置くと、自動で花火大会が始まります。

部屋の明るさや街の大きさ・高さは、MRの操作パネルで調整できます。MR終了は操作パネルの「鑑賞を終了してページへ」でブラウザ画面に戻れます。

## 橋の上から見る

「街に入る · 手前の橋」で、一番手前の橋に座る視点へ切り替えます。QuestのページからはVRで入れます。MR鑑賞中も操作パネル下の同じボタンで切り替えられ、部屋を隠して夜の街を表示します。

顔を上げて花火を、下を向いて川面を、左右を向いて街を眺められます。歩く・スティックで移動する操作はありません。花火大会は切り替え前の続きから流れ、同じボタンの「ミニチュアに戻る」で街全体の鑑賞へ戻れます。部屋の表示はMRから入った場合に戻ります。VRを終了する場合は、操作パネルの「鑑賞を終了してページへ」を押してください。

左コントローラーを握った手、またはコントローラーなしの左手を、手のひらが上に向くように返すと、小さな視点選択パネルが出ます。手を目線の少し下まで上げ、返したまま約0.3秒保ちます。上向きで持ち続けても繰り返し開きません。パネルは手を下ろしても残り、右手の人差し指でパネルに直接触れて選べます。指を離してから再び触れると次のクリックになります。コントローラーを持っている場合は、右コントローラー先端の小さな金色の目印で同じように直接タッチできます。タッチのときにトリガーを押す必要はありません。ビーム＋トリガーも使えます。手だけの操作はQuestのハンドトラッキングを有効にしてください。

サイドパネルは右Aで開閉、ビーム＋トリガーで操作できます。橋の視点では街の縮尺・床の高さ・距離・部屋の明るさは固定し、ミニチュアへ戻ると元の設定・配置を復元します。PCでは画面上の橋の視点へ切り替わり、ドラッグで上下左右を見回せます。

初版の街は既存モデルを100倍にした演出上の大きさです。橋の床から視点まで約1.2m、街の幅約320m。建物の作り込みは今後の課題です。音の素材・余韻は維持し、橋の視点では視点と打ち上げ位置の距離による到達差と、顔の向きに追従する立体音響を使います。

## 小さなガラスパネル

左手のひらを上に返して出す「クルッとパネル」の「時間と玉名を表示」で、経過時間と打ち上がった玉の名前だけを表示できます。同じメニューの「時間と玉名を隠す」で消せます。右の人差し指、または右コントローラー先端でタッチします。初期状態は非表示。ページにも同じ表示切り替えボタンがあります。

MR・VRでは視界の少し右下、約60cm先に、手で届く範囲に背景の透ける小さなパネルを置きます。顔を上げても頭に張り付いて追いかけず、表示した場所に留まります。橋／ミニチュアの切り替え時や一度隠して再表示したときは、新しい目線を基準に置き直します。操作パネルを閉じても残ります。下の細い白いバーにビームを合わせてグリップを押したまま動かすと、好きな位置に置けます。手だけの場合は、バーの近くで右の親指と人差し指をつまんで動かし、開くと離せます。追跡が切れたときやパネルを隠したときは掴みを解除します。

経過時間は大会の時計を使い、一時停止中は止まります。「試し打ち」「ひと休み」「大会終了／開始前」も時間の横で区別します。玉名は打ち上がった瞬間から表示し、上昇中に次の玉の種類・号数が分かるようにします。開花後も消えるまで表示を保ちます。同じ種類・号数の同時打ちは「×5」などとまとめ、異なる玉は併記。消えた玉の名前を残さず、打ち上げ中・開花中の玉がなくなったら「次の一玉を待つ」と表示します。千輪の子花火を待つ暗い間も、その玉の名前を保ちます。配色や章名・設定は載せません。beta.1.0.17の基本操作は制作者がQuest実機で成功を確認しました。今回の発射時の玉名表示は実機確認前で、性能の追加測定は未実施です。

## コントローラー操作（beta.1.0.22以降）

- 左X：クルッとパネルを開閉。左手を返す動きも開閉に使えます。閉じた後は、手を一度戻してから返すと再表示できます。
- 右A：サイドパネルを開閉。左Xと独立し、両方を表示できます。
- 右B：大会、または試し打ちの一時停止・再開。
- 左右のグリップ：パネルの白い棒、または街の台座へビームを合わせて掴み、押したまま動かします。街は左右・前後へ移動し、底面の高さを保ちます。橋の視点では街は移動しません。
- 街を掴んだ手のスティック：左右で街を回転、上で拡大・下で縮小。拡縮中も底面の高さを保ちます。
- パネルを掴んだ手のスティック：左右でこちらを向く角度に好みの左右角を追加、上で奥・下で手前へ。３枚とも同じ操作です。移動時の自動でこちらを向く動きと、追加した角度を保ちます。
- トリガー：パネルへビームを向けるとボタン選択、それ以外では一発発射。押し続けても連射せず、掴み中は発射しません。クルッとパネルの直接タッチも使えます。
- 試し打ちタブ：「この一発を試す」ボタンは選択中の玉を試します。トリガーは左右それぞれの仕込みを優先し、未仕込みの手だけ選択中の玉を使います。タブを選ぶだけでは大会を止めず、試し打ちの発射操作で試し打ちへ切り替わります。
- 「左トリガーに仕込む」「右トリガーに仕込む」：対象の手を先に選び、「種類／大きさ／配色」のタブから選んで「この玉を左／右に仕込む」で確定します。選択中の仮の玉は確定まで仕込みに影響せず、戻ると変更しません。仕込みは尺玉・二尺玉の代表的な８種（柳・銀かむろ・芯入り・八重芯・三重芯・四重芯・五重芯・千輪）に絞り、他の玉は試し打ちで選びます。種類ごとの号数制限も維持。大会中にも選べ、大会時計や試し打ちの選択欄を変えません。種類・号数・配色をそれぞれ覚えます。花火大会タブへ戻ると、左右トリガーでそれぞれの玉を大会へ追加できます。大会の時計を戻しません。未仕込みの手は選択中の玉を使います。一時停止中は右Bで再開してから発射します。

ブラウザ側も「花火大会／試し打ち／街・音／使い方」のタブで操作します。部屋で観る入口をサイドパネルの最上段へ配置しました。22の操作は制作者がQuest実機で「ほぼ完璧」と評価。25の火の点は制作者がQuestで「自分で上げてる感じがめっちゃ増した」と評価。26の左右の仕込み修正と、追加打ちの性能数値は実機確認前です。左右の仕込みは鑑賞中の状態で、ページを読み直すと解除します。

## トリガーから火を送る（beta.1.0.25以降）

コントローラーのトリガーで一発を打つと、先端から金色の火の点が短い尾を引いて弧を描き、狙いに近い川沿いの打ち上げ場所へ飛びます。ミニチュアは約0.55秒、橋では約0.70秒で着き、着地点の小さな光と0.25秒の間のあと、その場所から選んだ玉が打ち上がります。左右の仕込みと配色は押した瞬間に確定。自動の花火と、ページの試し打ちボタンは従来の直接打ち上げです。

押すたびに１発を送れます。手動は自動大会の８玉上限から分け、柳の尺玉５発と二尺の五重芯２発などを順番に追加できます。飛んでいる間は発射枠を確保し、大会の時計と予定を保ちます。手動の受付は既存・送り途中・新しい玉を合わせた18万点と送り途中32発を設計上の上限とし、実際のXRコールバックが１秒平均で12fps未満になると追加だけを待ち、20fps以上で受付を戻します。既存の玉は減らしません。これらは暫定の保護値で、Questの実際の限界を測定した数値ではありません。一時停止では火の点も停止。大会の停止・初期化・試し打ちへの切替・鑑賞終了・橋と街の視点切替・Questの休止では送り途中の火を取り消し、後から勝手に発射しません。パネルへの選択、グリップ中、手だけのピンチでは火の点を送らず、トリガーを押し続けても連射しません。

## 音と保存設定

「街と音」のパネルで音・音量・塔のライトアップを選べます。制作者が好評とした音は「リアル寄せ合成（テスト）」です。初回は既存実装の「現在の音」が選択されます。音の選択などはブラウザのサイト別設定に保存するため、別のURLで初めて開く際には選び直してください。

## 配信・更新

静的なHTML・JavaScript・音声ファイルだけで動作し、ビルド処理は不要です。MRにはHTTPS、またはQuest側のlocalhost接続が必要です。通常のLAN内HTTPではMRを開始できません。

更新時は `index.html`、`app.js`、`programs.js` の `?v=` をすべて同じ新しい値に揃えます。現在の値は `1.1.0` です。番号を更新する際は、`app.js` の `BUILD_VERSION` も同じ値に揃えます。

## 計測

「MR実機テスト」から計測結果を保存できます。表示されるFPSはXRコールバックの間隔から求めた値で、GPU・コンポジターの実測FPSではありません。初回のQuest実測では特別かむろ32,352点、最低28.7fpsを記録しました。約3万点の密度と迫力を優先し、FPSだけを理由に点数を減らしません。旧版 `1.0.0-beta.2` では点数を維持し、計測JSONに花火・灯り・パネル更新のCPU時間（`meanUpdateCpuMs`）も追加しました。この値はGPU時間やブラウザ全体のCPU時間ではありません。

## 部屋に入ったら、まず街を眺める（beta.1.0.28以降）

「部屋で観る」は大会を自動開始しません。ブラウザで大会や試し打ちをしていた場合も、MRへの入室が成功してから花火と送り途中を終了し、開演前の街へ入ります。最初の視点が取れた時に街を置き、サイドパネルの大会タブを表示。台座へビームを合わせてグリップで掴み、左右・前後に動かせます。掴んだままスティック左右で回転、上下で大きさを調整。サイドパネルの金色の「花火大会を観る」を押すと最初から始まります。入室の拒否・失敗だけでは元の大会を止めません。大会中の橋への切替は同じ大会を継続します。ブラウザから橋への直接VR入口も新しい大会を自動開始しませんが、すでにブラウザで流れている大会は継続します。28の入室の流れはQuestで本人確認前です。

MRへの入室直後は、街の左寄りにグリップ移動とスティックの左右回転／上下拡縮の案内を表示。最初の視点が取れた時から15秒間で、最初の0.45秒で浮かび、最後の1.5秒で消えます。案内は部屋に固定し、顔を向けるたびに追従しません。入力を遮らず、橋への移行や鑑賞終了で消します。パネルを出し直しても繰り返しません。サイドパネルの短い操作説明は残します。beta.1.0.29の入室体験は制作者がQuestで好評。案内が短いとの指摘から1.1.0で15秒へ変更し、パネルのスティックの奥行きも上で奥・下で手前に変更。これら２点の修正は実機再確認前です。

ブラウザ／MRの「使い方」タブには、街のグリップ移動・スティック調整・左X／右A／右B・パネルの白い棒・左右の仕込みとトリガー発射をまとめています。ブラウザ側は橋・ガラスパネル・手だけの操作も説明。大会を止めずに見返せます。
