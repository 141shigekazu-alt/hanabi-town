# 花火街 1.1.25 屋形船の遊覧・デッキ歩行

1.1.22の屋形船と1.1.21の修正を継承し、永代橋側から清澄橋の下を抜け、奥の三連橋の手前でUターン、再び清澄橋をくぐり永代橋の手前で折り返す航路に拡張。

渋滞がない一周は約11分3秒、最大約0.51m/s。２分かけた緩やかなUターン、上下揺れ・端のテレポートなし。清澄橋の床上高さと構造は保持し、橋桁の厚みを薄くして船首提灯上端と約22cmの隙間を確保。

川を走る４隻と鑑賞船を、向きと船体寸法で衝突判定。余裕のある航路ですれ違い、先の航路が塞がる時は減速して先に通し、空くと再発進。後ろの船も停止中の鑑賞船を貫通しない。花火の一時停止・XR休止時は鑑賞船も停止。

Questの乗り心地と床埋まり解消は実機確認待ち。デッキ内は実空間の歩行と左スティック移動に対応。MacではWASD。左右約3.6m、前後約13.1mの範囲でスティック移動でき、航行・旋回中も船に対する位置を保持。実空間の歩行は追跡のまま。

1.1.24：背景船の追従間隔を修正。速い船が追いつく前から減速し、船体間の約10m以上の余裕を維持。川端から現れる時も、前後が詰まっていれば待ってから入る。

1.1.25：後ろの柵を追加。橋の移動と同じ入力条件でデッキも歩けるようにした。
