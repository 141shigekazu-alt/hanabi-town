# My花火街 1.2.94

Quest 3で街と音楽に合わせた花火を楽しむWebXRアプリです。大型版1.3.0の前の調整版です。

## 今回の変更

- 右側のサイドパネルから開く子パネルを、親の左側（内側）へ少しずらします。前に浮く距離と大きさは保ち、閉じると親の位置へ戻ります。
- 保存したセットリストの「…」に「編集する」を追加。保存パネルと同じ⠿のドラッグで曲順を入れ替え、曲名の変更・曲を外す・外した曲を戻す操作ができます。長いセットリストはスティックで連続スクロールできます。
- 「変更を保存」までは下書きとして扱い、「変更せず戻る」や×で元のセットリストへ戻せます。最低１曲は残します。曲名の文字入力は既存の標準入力欄を使い、MRへ戻って編集中のパネルを続けられます。
- 更新するのは、そのセットリストの曲順・表示名・曲数だけです。曲ごとの保存済み花火、音源、元のお気に入り、ほかのセットリストは変更しません。再生中の大会は現在の順番を保ち、編集内容は次のセットリスト再生から反映します。
- 1.2.93の音響データ再利用を継承。本人のQuest確認では、開演時のビーム停止はほとんど感じないレベルになりました。

## Questの更新

ネット接続中にリロードし「保存更新」を押します。「保存済み 1.2.94」を確認して、もう一度リロードしてからMRへ入ってください。

## 音声リクエスト（テスト版）

「演出を調整する」のマイクから最大20秒。準備中の表示が消えて録音中になってから話し、「停止」で終了できます。文字と希望を確認し、「このイメージで打ち上げる」で反映します。
「全体はしっとり、大玉はところどころ、最後は盛大に」のように全体・量・締めを分けて扱います。認識モデルは前版と同じです。通常の録音は処理後に破棄し、外部へ送りません。初回だけ端末内認識のモデルを取得します。

## 保存と配信

保存済みの構成や音源の原本は書き換えません。新しい構成は「打ち上げ玉の構成を変える」から作成してください。以前の保存済み1.2.55と別バージョンは残しています。
静的HTTPサーバーでフォルダー全体を配信できます。MRはHTTPSまたはlocalhostが必要です。ベンダーとフォントのライセンスはvendor/とfonts/に同梱しています。
