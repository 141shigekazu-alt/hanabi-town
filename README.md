# 花火街 1.1.37（ベータ）

厩橋前の折り返しで交通待ちが長引く処理を修正しました。旋回範囲が空いたあとに予約を取る方法を改め、折り返す手前で後から来る船の進入を待たせます。すでに範囲内にいる船は先に通し、空いたら屋形船が回り始めます。旋回が終わったら範囲の予約を解除します。船体の接触判定は維持しています。

Uターンを2分40秒から2分へ短縮しました。軌跡と一方向へ回る動き、回り始めと終わりの滑らかさは保ち、直進の巡航上限0.54m/sも維持しています。交通待ちなしの一周は約16分2秒です。

下船後の航行、現在位置からの再乗船、「出航位置に戻る」と曲・花火の再生継続、「街を見下ろす」が先頭のメニューは維持しています。

通常の交通25条件と、乗船時刻・途中の一時停止・出航位置へ戻す操作を変えた36条件を検証。各条件で2周以上、船体接触と停止し続ける状態がないことを確認しました。XRの追跡姿勢・歩行・休止復帰・視点切替、3曲連続・終演後周回、36ファイル3曲のオフライン保存も検証。Macで厩橋側の折り返しと公開版の表示・更新保存を確認しました。新版のQuest 3での速度・停止改善の実機確認はこれからです。

Wi-Fi接続後「オフライン保存を確認・更新」→「保存済み1.1.37」→再読み込みし、左上が1.1.37になったことを確認してください。
