# 花火街 1.1.48（ベータ・Quest聴感調整）

Questでの本人の聴感を受け、録音モードの5号と尺・二尺を調整しました。Macのスピーカーでは分からなかった寸詰まり感と過剰な残響に対応する試作です。今回の自然さの採否は、Quest実機でこれから確認します。

好評の3号は発射・開花の波形、音量、音程の個体差を維持しています。5号の発射は共通の0.32秒切り出しから0.70秒へ延ばし、最初の0.12秒の立ち上がりを保ちながら、後半の減衰と最後のフェードを緩やかにしました。5号の開花録音は元から全長を使っていたため、途中切断はありません。録音の先頭0.20秒を保ち、元の後半の音量だけを滑らかに最大1.45倍へ上げました。録音の長さ・音程・位相を変えず、エコーや複製の尾は追加していません。

尺・二尺の主開花音から、従来重ねていた約4.8秒の人工残響を外しました。録音自体の低音と衝撃、二尺の低音補強・音圧は維持しています。二尺千輪の子玉の残響送りは90％減らし、かむろ・柳の尾の追加残響も抑えました。千輪の音程・低音と音量の大小差、かむろ尾の約1.5倍の長さ、開花音から尺1.5秒・二尺2秒後の入りは維持しています。曲の有無で音を切り替えず、同じ音の設定を使います。

笛の入り0.5秒と録音6種、音楽MIX35％、二尺の中心高度2.00、街と屋形船、3曲の時刻と順番「花火の夜 → 夏の名残 → パステル・パラサイト」を保持しています。必要な録音26点だけをJS配列として組み込む方式と、効果音の個別ファイル・書き出し機能を設けない方式も維持しています。

実アプリのXR・船・曲・休止再開と笛・高さ、素材の割り当てと3号の波形一致、ChromeのWeb Audioによる多重発音・音割れ・予約取消・3号の出力一致・大玉の残響低減・実曲の終わりから最後の二尺への出力計算、38ファイル3曲のオフライン保存と失敗時復旧を確認しました。計算結果はQuestの聴感や負荷の保証ではありません。

Questで「オフライン保存を確認・更新」から保存し、「保存済み1.1.48」→再読み込み→左上1.1.48を確認してください。まず曲なしの3号・5号・尺・二尺、その後にパステル・パラサイトの曲が終わった最後の一発を聴き比べてください。
