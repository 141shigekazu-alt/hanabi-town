# 花火街 ベータ版1.3.11

花火街は、Meta Quest 3（クエスト）のMRで、部屋に置いた小さな街と花火大会を楽しむWebアプリです。好きな曲を取り込んで音楽花火を自動構成。日本語の音声リクエストや、自分だけのセットリスト保存にも対応。ベータ版公開中。

公開先：https://141shigekazu-alt.github.io/hanabi-town/

## 1.3.11：型物がポンポン続くパートと選択した配色

短いまとまった連発に加え、２／３号が曲の２〜４小節ほど続く場面を追加。曲なし／仕込み画面の「選んだ型物を10秒続ける」では約10秒かけて上がります。後続の予約場面に入り込まないよう長さを調整します。

選んだ型物の継続打ちが配色欄の指定を無視していた不具合を修正。ハートは選んだ色、二重ハートは選んだ内外配色を全10発へ渡します。ニコちゃんの黄輪郭・緑目・赤口と、ガチャ／ひと巡りの配色変化は従来どおりです。継続打ちはQuestで本人が「可愛くてよかった」と確認、配色修正はコード検証で確認済みとして追加試写不要との指示を受けています。

## 1.3.10：ハートとニコちゃんの型物花火

ハート・二重ハート・ニコちゃんを追加。２・３号が街のあちこちから10発前後のまとまりで上がり、ときどき左右の５号ニコちゃんが添わります。形や向きの自然なばらつきはQuestで採用確認済み。ニコちゃんは黄色い輪郭・緑の目・赤い口、二重ハートは外桃／内紅と外紅／内桃の両方を選べます。

「型物を入れる」ボタンから種類（ハート・二重ハート・ニコちゃん・まぜる）と量（少し・多め・たくさん）を指定できます。ブラウザ・MR共通で、音声認識なしで選んだ型物を確実に構成へ入れます。ガチャの型物候補も残しています。

音声リクエスト「型物入れて」「ハートを入れて」「ニコちゃんを入れて」「スマイル入れて」に対応。認識された希望を「このイメージで打ち上げる」で新しい構成へ反映します。保存済みの構成・セットリスト・曲名・音源は変更しません。MRの仕込み画面でも一発・10連発・ひと巡りを試せます。

## 1.3.9の新機能：現場モードのMR背景

橋・屋形船のデッキ・両屋上席を「現場モード」と呼びます。入る時は「部屋の明るさ」0％の黒い夜空から始まり、同じスライダーを上げると現実の部屋が透けて見えます。100％で背景が完全に透け、街・花火・家具はそのままです。

現場内で場所や屋上席を切り替えても調整値を引き継ぎ、街を見下ろす視点へ戻ると元の明るさを復元します。再び現場モードへ入る時は0％から。曲名の編集で一時的にブラウザへ出る場合は、編集前の明るさも復元します。現場の調整値で見下ろしの保存設定を上書きしません。

直接現場から入る時もimmersive-arを優先。MR非対応機器では従来のVRに入り、透過できない明るさ操作を無効表示にします。新しいスライダーや保存領域は追加しません。Quest試作では本人が背景の透過と既存スライダーの動作を確認しています。

## 1.3.8の改善：曲名一覧をすっきり表示

取り込み曲の後ろに自動で付けていた「（取り込み）」の目印を外しました。すでに登録した曲にも適用されます。曲名として自分で入力した文字、標準４曲の「オリジナルプログラム」、構成番号はそのままです。曲名・音源・お気に入り・セットリスト・曲順のデータは変更しません。

## 1.3.7の新機能：右スティックで向きを変える

橋・屋形船のデッキ・両方の屋上席で、右スティックを左右へ倒している間、その場でなめらかに向きを変えられます。倒す量で速さが変わり、離すと止まります。左スティックはこれまでどおり前後左右の移動です。

パネルの掴み・調整・スクロール中はそちらの操作を優先します。立ち位置と椅子ゾーンを保ち、船の航行でも向きが戻らないようにしています。Quest試作で滑らかな旋回の操作感を確認し、1.3.7として公開しました。

## 1.3.6の案内文

保存後の操作を「↻ ブラウザをリロード」に統一しました。案内は「保存が完了しました。ブラウザをリロードしてください」。ボタンを押すと、そのブラウザをリロードして保存した版へ切り替わります。

## 1.3.5のMR復帰保護と端末内記録

- 一度の描画例外で次のフレーム予約が失われる処理を修正。XRの一時的なpose失敗や復帰途中の例外から、後続フレームで再試行できます。アンカーの待ち時間は同じ単調時計で判定します。
- 入室・改名復帰の段階、街の可視性と座標、例外を直近96件まで端末内に保存。曲名・音源は記録せず、外部送信は行いません。「街・音」内の「MR実機テスト」→「MR復帰の記録を保存」でJSONを保存できます。
- これはコードで再現した停止経路への対策です。本人のQuestで起きた断続的な街非表示の原因・解消を確定した意味ではありません。

## 1.3.4の改善：TCの曲名と曲選択の並び

- TCの時刻の右に、現在の曲名を表示します。構成番号は付けず、長い曲名は２行まで。曲なしの大会では曲名を表示しません。
- 標準４曲は先頭のまま、取り込み曲は変更後の表示名を日本語の名前順に並べます。アーティスト名を先頭に付けた曲がまとまります。曲の選択・名前変更・再読み込みで同じ順序になります。
- 曲を選ぶ一覧だけの変更で、保存セットリストの順番や音源・解析結果は変更しません。

## 1.3.3の変更：タイトル下から更新・保存

- タイトル近くの版表示の下に「最新版に更新・保存」を独立して表示。保存中の進捗、最新版を保存済みか、ブラウザのリロードが必要かも同じ場所で案内します。
- 新しい版を保存した後は「↻ ブラウザをリロード」で切り替えられます。保存曲・お気に入り・セットリスト・設定の領域は変わりません。
- 1.3.2以前を保存済みの方は、今回だけ従来の右パネル末尾から保存を更新し、ブラウザをリロードしてください。以降はタイトル下の入口を使えます。

## 1.3.2の新機能：ビルの屋上の桟敷席

- クルッとパネルの「ビルの屋上から見る」から、柵・丸テーブル・椅子のある桟敷席へ入れます。
- 最初は花火の迫力を楽しむ近い席。屋上では同じ一行で「近い席／全景の席」を選べます。サイドパネルの「街・音」からも切り替えられます。
- 近い席は木の天板と深緑の椅子、全景の席は黒い天板と落ち着いた革色の椅子。花火と食事を楽しめる少し斜めの配置です。
- 左スティックで柵のすぐ内側まで移動できます。椅子を離れると目線が約50cmなめらかに上がり、戻ると座った目線へ下がります。頭の覗き込みでは切り替わりません。
- 席や橋・船を切り替えても、大会は続きます。取り込んだ曲・お気に入り・セットリスト・設定の保存領域は同じです。

## 1.3.1の修正

- 曲名の編集で一度ブラウザへ出た後、編集欄の「MRに戻る」と通常の「MRで観る」のどちらから入っても、編集前の街の位置・向き・大きさとパネルを復元します。MR開始を拒否・失敗した場合も、復帰情報を保持して再試行できます。
- 古い位置の目印の削除が遅くても、街の配置・表示を待たせないようにしました。新しい目印の記録を、古い処理の完了で消さないようにしています。
- この２経路を模擬検証とブラウザ操作で確認しています。利用者が報告した実Questの断続的な症状の原因が、この２点だったと断定するものではありません。修正後も実機で経過を確認します。

## 1.3.0からの機能

- 自分の音楽を取り込み、端末内で解析して音楽花火を自動構成。曲調に合わせた作風・配色・花畑・海・田園などの演出を組み合わせます。
- 日本語の音声リクエストを演出へ反映するテスト版。マイクの準備表示、最大20秒の録音と手動停止、文字と希望の確認・取り消しに対応します。「このイメージで打ち上げる」を押して反映します。
- お気に入りの音楽花火と、名前付きセットリストを保存。セットリストの名前から曲目・曲順を確認し、そのままドラッグで順番変更・曲名変更・曲の除外ができます。大会は独立した▶から始めます。
- ゴールド標準とサイバーのパネル配色。街・音で切り替えられます。子パネル、連続スクロール、トリガーへの仕込み、TCと玉名、音量・部屋の明るさを調整できます。
- 花・稲穂・蝶・惑星・鼓などの演出と、開演時の音響データ再利用による負荷軽減を含みます。

## 標準の音楽花火

「花火の夜」「夏の名残」「パステル・パラサイト」「もう一度だけ」の４曲です。
標準の構成は「曲名（オリジナルプログラム）」、自動構成は「曲名　構成−１」などと表示します。自分で取り込んだ曲は、その端末に保存されます。

## Questの更新

Wi-Fiにつながった状態で、タイトル下の「最新版に更新・保存」を押してください。「1.3.9」の保存完了後、「↻ ブラウザをリロード」で切り替わります。1.3.2以前を保存している場合は、今回だけページ右側・最下部の旧保存欄から更新してください。取り込んだ曲・お気に入り・セットリストを残すため、サイトデータを消す必要はありません。

## 音声リクエスト（テスト版）

「演出を調整する」のマイクから話します。準備中の表示が消えて録音中になってから話し、「停止」で終了できます。
「全体はしっとり、大玉はところどころ、最後は盛大に」のように伝え、文字と解釈を確認してから反映します。通常の録音は処理後に破棄し、外部へ送りません。認識モデルは初回に取得します。聞き間違いや希望の解釈には制限があり、引き続きテスト版として提供します。

## ベータ版について

1.3.0までの確認済みの機能を引き継ぎ、1.3.1でMR復帰経路を修正しています。利用者から、再現を試みると正常に動作する一時的な違和感の報告があります。原因や症状は特定できておらず、再発時に手順を確認します。
保存済み1.2.55と1.2.96の手元版は別に保持しています。今後の試作品「My花火街２」「My花火街３」などは、本家と別URL・別の保存領域で検証し、採用分を本家へ反映する方針です。

## 配信とライセンス

静的HTTPサーバーでフォルダー全体を配信できます。MRはHTTPSまたはlocalhostが必要です。ベンダーとフォントのライセンスはvendor/とfonts/に同梱しています。
