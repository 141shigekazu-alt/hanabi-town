# 花火街 — ベータ版1号

部屋の中にミニチュアの街を置き、座ったまま花火大会を眺めるWebXR MRアプリです。Meta Quest 3のQuest Browserで利用します。

## バージョン

- ベータ版1号：`1.0.0-beta.1`
- 試作1.4.15を基に、表示名とキャッシュ識別子を更新しています。花火、音、大会進行、MR操作の実装は同じです。
- Quest 3での試作1.4.15の動作・文字の読みやすさは制作者が確認済みです。公開HTTPSサイトからの起動とUSBを外した動作は、これから実機で確認します。

## Quest 3で使う

1. Quest Browserで公開HTTPS URLを開きます。
2. 左上の版表示が「ベータ版1号」になっていることを確認します。
3. 「自分の部屋で見る」を押し、ブラウザのMR許可画面に従います。
4. 街を置くと、自動で花火大会が始まります。

部屋の明るさや街の大きさ・高さは、MRの操作パネルで調整できます。MR終了は操作パネルの「MRを終了」でブラウザ画面に戻れます。

## MR操作

- 左コントローラーのX：操作パネルの表示・非表示。
- コントローラーのビーム＋トリガー：パネルを操作。
- パネル下の白い横棒：ビームを合わせ、トリガーを押したままパネルを動かす。
- 左トリガー：パネルや白い横棒以外にビームを向けて街の位置を合わせる。街を掴む操作ではありません。
- パネルを閉じた状態の右トリガー：大会を一時停止・再開（試し打ちモードでは大会を自動開始しません）。
- 「大会を止める」や試し打ちのボタン：試し打ちモード。大会へ戻るには「花火大会を始める」または「大会を最初から」を押します。

## 音と保存設定

「街と音」のパネルで音・音量・塔のライトアップを選べます。制作者が好評とした音は「リアル寄せ合成（テスト）」です。初回は既存実装の「現在の音」が選択されます。音の選択などはブラウザのサイト別設定に保存するため、別のURLで初めて開く際には選び直してください。

## 配信・更新

静的なHTML・JavaScript・音声ファイルだけで動作し、ビルド処理は不要です。MRにはHTTPS、またはQuest側のlocalhost接続が必要です。通常のLAN内HTTPではMRを開始できません。

更新時は `index.html`、`app.js`、`programs.js` の `?v=` をすべて同じ新しい値に揃えます。現在の値は `20261005-beta1` です。

## 計測

「MR実機テスト」から計測結果を保存できます。表示されるFPSはXRコールバックの間隔から求めた値で、GPU・コンポジターの実測FPSではありません。特別フィナーレの最大粒子数は32,364点です。公開版のQuest 3実機性能は測定前です。
