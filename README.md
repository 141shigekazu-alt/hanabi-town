# My花火街 1.2.77 · 自分のセットリストを保存

公開URL： https://141shigekazu-alt.github.io/hanabi-town/?build=1.2.77

♥一覧で曲を選んで並べ、「このセットリストを保存する」を押すと、曲順と各曲の花火構成をひとつの大会として保存できます。「セットリスト＿０１」から順に名前が付き、メニューの「名前を変える」で好きな大会名へ変更できます。複数の大会を残せます。

サイドパネルの「このセットリストを観る」から呼び出せます。保存パネルでは「♥の曲を選ぶ」と「保存したセットリスト」を切り替えられます。ブラウザでは呼び出した大会を準備し、いつもの開演ボタンから開始。MR内では呼び出すと連続鑑賞を開始します。

各曲は余韻が終わるまで再生し、３秒空けて次の曲へ進みます。「最初から」や終了後の「もう一度」ではセットリストの先頭曲へ戻ります。

保存済みの大会は、その時の曲順・花火・音源の組み合わせで再生します。後から元の♥を並べ替えたり一覧から削除しても、保存済みセットリストは変わりません。音源は共通の保存データを使うので、セットリストを増やすたびに同じ音源を複製しません。

保存先は端末内のブラウザです。サイトデータを削除すると保存も消えます。公開HTTPSとMac経由のlocalhostは別の保存先です。

1.2.77公開版です。既存の取り込み曲と♥は同じ公開サイト内で引き継ぎます。オフラインで使う場合は「オフライン保存を確認・更新」から「保存済み 1.2.77」になるまで待ってください。保存済み55と公開76の元ファイルは別途保持しています。
