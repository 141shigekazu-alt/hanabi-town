About Usage Counts

Hanabi Town, operated by Shigekazu Ishii, counts daily page views, MR/VR entries, show starts, and starts using imported music to improve the experience.

Only daily totals are stored

The usage database stores only the date in Japan, the action type and the total count. No cookies, user IDs or device fingerprinting are used. We do not identify individuals, so these figures do not show unique or returning visitors. Repeat views and entries are counted again.

Track names, audio files, voice input, favorites and location data are not sent. The current URL and referrer are not sent as usage data. Requests go to a dedicated Cloudflare Worker. Cloudflare may process IP addresses to provide its service, but Hanabi Town's usage database does not store IP addresses, browser information or individual access histories. Worker request-log storage is disabled.

Stopping usage counting

Open About Usage Counts in Hanabi Town to stop sending counts from this browser. Browser storage is used only to remember that preference. A previous choice to decline Google Analytics remains respected, as do Do Not Track and Global Privacy Control.

Offline actions and failed requests are not queued and sent later. These counts are therefore not a complete record of all usage.

Moving from Google Analytics

Since version 1.3.21, Hanabi Town does not load Google Analytics or send usage data to it. Data previously collected with permission in version 1.3.19 remains in Google Analytics. New counts are handled separately and are not retroactively added to or combined with the old data.
